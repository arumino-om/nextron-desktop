**なぜ要るか。** システムコール番号・エラーコード・検査の実行順・
グローバル名・論理デバイス名は、**テキストが衝突しなくても意味が衝突する**。
2 つの作業が同じ番号を別の意味で使うと、どちらのテストも通ったまま
マージした瞬間に壊れる。しかも壊れ方が「呼んだ覚えのない機能が動く」
なので原因が見えにくい。

レーンごとに**帯**を予約し、「自分の帯からだけ取る。空いていても他の帯には
入らない」という規律にした。帯が足りなくなったら表に 1 行足す
（衝突しても解決が自明な形）。

- **受入条件**（通過）
  - いま使っている番号が全部表にあること（`syscall.h` の 1〜119、
    検査の order 100〜340、`MGR_*`、論理デバイス名）
  - レーンの一覧が `docs/parallel.md` と一致していること
