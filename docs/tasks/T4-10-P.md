# T4-10-P ポインタ制御 (§2.6)

- **状態**: 完了
- **委譲**: ○

- 依存: DP の基本部分 (T4-10)・イベント管理 (§1.7)
- 置き場: `src/lib/dp/pointer.c`（LGPL 側。J2 / 規律 R14）
- 実装: `gini_ptr` / `gdsp_ptr` / `gset_ptr` / `gmov_ptr` / `gmot_ptr` /
  `gget_ptr` ＋ 本OS 内部の `gptr_follow`

**ポインタは描画環境 (GID) に属さない。**「スクリーン上の表示に
オーバーラップする形で表示される」画面全体で 1 つの資源なので、§2.6 の
関数だけが gid を取らない。クリッピングも前置長方形も掛けない
（掛けたら手前の窓の上に出られない）。

**消したものは save-under で戻す。** ハードウェアカーソルが無いので、
描く前に n×n 画素を退避し、消すときに書き戻す。仕様が `gdsp_ptr` に
**消去要求数（カウンタ）**を持たせているのはこのためで、描画する側が
消去 → 描画 → 表示で囲む約束になっている。真偽値にすると入れ子の
描画で早く出てしまう。

**ポインタサイズは 16。** 仕様は「標準的には 24 であるが、インプリメント
によっては、16、32 等の場合もある」としている。内蔵フォントが 16 ドット
固定なので揃えた。アプリ定義イメージは仕様どおり 64 まで受ける。

**標準形状は文字で描いた。** 16 進のビットパターンで書くと 1 ビット
ずれても気づけない。'X' と '.' の 16 行で書き、縁取り（背景色）は
8 近傍から自動で付ける。縦横の別がある形状（VGRIP / HGRIP など）は
いまは同じ絵を使っている。仕様が区別しているのは「どの方向に動かせるか」
であって、絵を必ず変えろとは言っていない。

- **受入条件**（すべて通過）
  - 消去要求数がカウンタとして働く（2 回消して 1 回表示ではまだ消えている）
  - 強制表示要求で 0 に戻る
  - data / mask の 4 通り（前景色 / 背景色 / 透明 / 反転）が画素で一致する
  - **消したら下地が元に戻る**（save-under）
  - 追従状態では `gmov_ptr` が 1 を返して何もしない
  - 画面外は `EG_PAR`
