# T6-01 PCIe の列挙と MSI-X

- **状態**: **完了** — arm64 で列挙と MSI-X の構成まで。割込みの到達は L5 (LAPIC) の後
- **委譲**: ○

- 依存: なし（**arm64 の `virt` で先に通せる**。x86_64 を待たない）
- 参照: **詳細 F8** / 規律 R19 R2 R18 R29 / `include/btron/machdesc.h` /
  `src/drivers/virtio/mmio.c`（「枠の存在と中身は別」の先例）
- 置き場: **カーネル**。詳細 F1 の表で「ドライバより先に装置を見つける層で、
  これが無いとどのドライバも始まらない」として理由付きで例外にしてある
- やること
  - ECAM の枠を **ACPI の MCFG** と **DT の `pci-host-ecam-generic`** から読み、
    `MachDesc` に入れる（R19。アドレスを直書きしない）
  - 構成空間の 8 / 16 / 32bit。拡張構成空間 (256〜4095) まで届くこと
  - バス 0 から深さ優先の列挙。ブリッジの secondary bus・マルチファンクション・
    クラスコードでの検索
  - BAR の読み出しと `hal_vm_map_device()` による写像（R18 の MMIO 区画）
  - **MSI-X（持たない装置向けに MSI も）の構成**。宛先の割り当ては
    `hal_msi_alloc()` でアーキ側へ委ねる — PCIe 層は宛先を知らない
- 触った: `include/btron/pci.h`（新規）＋ `src/drivers/pci/{ecam,msi}.c`（新規）＋
  `include/btron/{intc,machdesc}.h` ＋ `src/kernel/boot/{acpi,fdt,machdesc,bootlog}.c` ＋
  `src/kernel/hal/arm64/gic.c` ＋ `src/kernel/core/tests/pci.c`（新規。order 760）
- 検査区分の order: **760**（`registry.md` §2 の L11 帯）
- **受入条件**
  - `MachDesc` の ECAM の枠が **DT 経路と ACPI 経路で一致する**
    （既存の相互検証と同じ形。arm64 の 2 構成で確かめる）
  - QEMU の `virt` で装置が列挙され、個数とクラスコードが出る
  - BAR を写して読み戻せる
  - **MSI-X テーブルを構成できること**。割込みが実際に届く検査は LAPIC が
    要るので T1-11 の残り（L5）の後。arm64 は ITS が無いので `E_NOSPT`（F8）
  - ハードウェアのアドレスを 1 つも直書きしていない（R19）

## 判明したこと

**(57)〜(61)** は `design-issues.md` §6 に入れた。要点は 3 つ。

- **MSI-X テーブルは BAR の中にある**ので、Command の MEM を許さないと書いた値が
  どこにも届かない（ファームウェアは使い終わった装置の応答を落として渡してくる）
- **BAR の大きさを測ることは、装置の応答を一時的に止めることである。**
  実機では GOP のフレームバッファが表示装置の BAR そのものなので、
  画面を描いている装置は測ってはいけない
- **逆テスト 4 つが全部通った。** 同じ実装で書いて同じ実装で読み返す検査は
  何も確かめていない。仕様の配置を検査の側に独立に持たせて初めて落ちた
  → 規律 **R32**

## この土台へ移すときに変えたところ

- 検査を**登録制**にした（`BTRON_TEST_GROUP(..., 760, TST_PHASE_PROC, tst_pci)`。W0-1）
- 起動時の ECAM の表示は `src/kernel/boot/bootlog.c` へ（`boot.c` から移っている）
- ソースの列挙は `src/drivers/sources.cmake` へ（W0-2）
- 規律の番号を **R30 → R32** に付け替えた（この土台では R30 が「x86_64 は位置独立に作る」）
- ctest の期待値を **「PCIe 装置 : 2 個」** にした — T3-03 で `-drive if=virtio`
  （virtio-blk-pci になる）をやめて `-device virtio-blk-device`（mmio 版）にしたので、
  PCI バスに居るのはホストブリッジと virtio-net の 2 個である
