# T4-12 ポインタの状態を全プロセスで 1 つにする

- **状態**: 完了（書き残しの正体。置き場はカーネルが画面と一緒に貸す）
- **委譲**: ○

- 依存: T4-11・T5-04（外殻が別プロセスに居ること）
- 触った: `include/btron/dp.h`（`PtrShared`）＋ `include/btron/screen.h`
  （`Screen.ptr`）＋ `src/kernel/screen/fb.c`（置き場の用意と貸し出し）＋
  `src/lib/dp/pointer.c`（共有の置き場を見る）＋
  `src/subsystems/window/winman.c`（描く前に消す）

**ポインタは画面に 1 つしか無いのに、DP はプロセスごとのライブラリ**
（詳細 E1）だった。静的変数で持っていたので、プロセスごとに別の
ポインタ状態ができていた。これが画面の**書き残し**の正体である。

- ウィンドウマネージャ（別プロセス）はドラッグの影を描く前に
  `gdsp_ptr(0)` で消していたが、消えるのは**自分のプロセスの**
  ポインタで、画面に出ている本物は消えない
- その `gdsp_ptr(1)` が**自分が思っている位置**（動かしていないので
  PD の初期位置 = 画面の左上）にポインタを描く。動かす側は別の
  プロセスなので、そこに描かれたポインタは誰も消さない。
  **ドラッグするたびに画面の左上に矢印が残っていた**
- 退避した下地が別プロセスの描画で古くなり、動かしたときに
  古い絵が書き戻される

**置き場はカーネルが画面と一緒に貸す。** 画面の持ち主はカーネル
（E24 / 規律 R18）なので、ポインタの置き場もそこに付ける。
`screen_init` が物理ページを取り、`screen_lend` がプロセスへ写す
（`Screen.ptr`）。**プロセスごとに違う仮想アドレスで見える**ので、
中に生ポインタは置かない。大きさだけを約束 (`PTR_SHARED_SIZE`) にして、
中身の解釈は DP に閉じる（カーネルは `PtrShared` を読まない）。

**マネージャは描く関数の中で消す。** `winsrv_loop` の入口で囲っては
いけない —— `wget_evt` は 10ms ごとに来るので、そこで消して出すと
ポインタが点滅する。移動・変形は何度も描くので、外側でも囲って
1 回の消し・出しにまとめる（消去要求は数なので入れ子にできる）。

- **既知の制限**
  - 共有状態に排他が無い。EL0 から使えるミューテックスがまだ無いので
    （システムコールが無い）、2 つのプロセスが同時にポインタを描くと
    一瞬乱れることがある。SMP はまだ無く、次の移動で直るので実害は
    小さいが、`loc_mtx` を EL0 へ通すときに直す
  - 画面が無い構成ではプロセスごとの器に落ちる（揃える相手が居ない）
- **受入条件**（すべて通過）
  - **別のプロセスに作業領域を塗らせてもポインタが残る**
    （共有を切る / マネージャが消さない、のどちらでも落ちる）
  - 塗った後に消すと、**塗った後の**下地が出る（退避が更新されている）
  - `PtrShared` が貸し出し枠に入る（`_Static_assert`）
