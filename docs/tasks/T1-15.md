# T1-15 ACPI 経路での装置列挙
- **状態**: 未着手（**DSDT の AML を読む必要がある**。それまで入力装置は `acpi=off`）
- **委譲**: ○

- 依存: なし（ACPI パーサは既にある）
- 問題: QEMU + ArmVirtQemu は既定で ACPI を渡してくるが、
  virtio-mmio の枠は DSDT の **AML** の中（`_HID` = "LNRO0005"、
  `_CRS` にアドレスと割込み）にある。MADT / GTDT のような固定書式の
  表ではないので、いまのパーサでは届かない
- 選択肢
  1. 最小の AML 歩行器（`DefDevice` / `DefName` / `DefBuffer` と
     `_HID` / `_CRS` だけ解釈する）を書く
  2. PCIe を列挙する（MCFG で ECAM が取れる）。ただし割込みが
     `_PRT`（また AML）か MSI-X（GICv3 ITS / GICv2m）になる
- それまでは入力装置を使う構成は `virt,acpi=off` で動かす
