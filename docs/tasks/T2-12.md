  `M_COMMON`(0x1) / `M_SYSTEM`(0x3) / 指定なし（ローカル）の 3 択で、
  **ローカル / 共有 / システムの区別はプロセスのアドレス空間が無いと
  意味を持たない**。仕様も「ローカルメモリは獲得したプロセスからのみ
  アクセス可能」「プロセス終了時に自動的に解放される」と規定している
- 区画（§3.2 に下位半分の分割を追記）

  | | | |
  |---|---|---|
  | ローカル | `BTRON_PROC_LOCAL_BASE` | 下位半分 = 正。プロセスごとの空間へ張る |
  | 共有 | `BTRON_COMMON_BASE` | 上位半分 = 負。全プロセス共通 |
  | システム | `BTRON_SYSTEM_BASE` | 上位半分 = 負。`USER` を付けない |
