- 依存: **T6-06**
- 参照: `src/drivers/virtio/input.c`（投入口の先例）/ **F3** の帰結
- やること: HID ブートプロトコル（キーボード 8 バイト / マウス 3〜4 バイト）を
  インタラプト転送で読み、`evt_set_kbd` / `evt_set_pda` と同じ口から
  イベント管理へ入れる。`"kbd"` / `"pd"` の登録は**先着 1 台**
- **受入条件**
  - QEMU `-device qemu-xhci -device usb-kbd -device usb-tablet` で、
    **既存の入力装置の検査がそのまま通る**
  - virtio-input と同時に挿しても**二重登録にならない**（先着が名前を取る）
