- **状態**: 完了（`tools/mkfont.py`。日本語字形を優先）
- **委譲**: ◎

- `tools/mkfont.py` が `$UNIFONT_SRC` の `.hex` から C ソースを生成する。
  **CJK は日本語字形 (izmg16) を中国語字形 (wqy) より優先**
- 残り: `IDXWDATA` 形式（B7）への対応と、フォントをカーネルに埋め込むのを
  やめてデータボックスへ移すこと（Phase 3 のファイルシステム待ち）
- **当初の受入条件**
  - **フォントデータそのものをリポジトリにコミットしないこと**（詳細 B8）

  - 変換結果に対して「指定した文字のビットマップが取れる」テストが通ること
