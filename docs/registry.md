# 番号と名前のレジストリ

**並列に作業するときの衝突を避けるための予約表**（規律 **R29**。W0-3）。

システムコール番号・エラーコード・検査の実行順・グローバル名・要求番号は、
**テキストが衝突しなくても意味が衝突する**。2 つの作業が同じ番号を別の
意味で使うと、どちらのテストも通ったままマージした瞬間に壊れる。
しかも壊れ方が「呼んだ覚えのない機能が動く」なので原因が見えにくい。

## 使い方

1. 作業を始めるとき、**自分のレーンの帯からだけ** 番号を取る
2. 帯が足りなくなったら、この表に新しい帯を追記してから使う
   （帯の追加はこのファイルの 1 行で、衝突しても解決が自明）
3. 他のレーンの帯には絶対に入らない。空いていても入らない

レーンの定義は [`parallel.md`](parallel.md)。

## 5. マネージャの要求番号 (`msg.func`)

各サーバの中だけで一意。**サーバをまたいで同じ番号を使ってよい**
（宛先ポートが違うので衝突しない）。1 つのサーバの中では
`1` から順に振り、`0` は使わない（未設定と区別するため）。

| サーバ | 使用中 |
|---|---|
| `FONTMAN` | 1 `FONT_GET_INF` / 2 `FONT_GET_IMG` / 3 `FONT_SHUTDOWN` |
| `WINMAN` | `WF_*`（`include/btron/winmsg.h`）|

## 6. 論理デバイス名 (§1.8)

仕様はデバイス名を実装定義としている（§1.8.2）。
**物理デバイス名 + ユニット番号**の形を守ること（`rda0` の `0`）。

| 名前 | 装置 | 状態 |
|---|---|---|
| `com` | シリアル | 実装済 |
| `rda` | RAM ディスク | 実装済 |
| `kbd` | キーボード | 実装済 |
| `pd` | ポインティングデバイス | 実装済 |
| `vda` | virtio ブロックデバイス | **実装済**（`hda` を避けたのは ATA を指すため）。サブユニットが GPT の区画 |
| `fda` | フロッピー（交換形式。T3-01） | 予約 |
| `prn` | プリンタ | 予約 |
| `net` | ネットワーク | 予約 |

### 検査の文脈 (`TST_PHASE_*`)

| 値 | 文脈 | いつ走るか |
|---|---|---|
| `TST_PHASE_KERNEL` | プロセスに属さないカーネルタスク | 常に |
| `TST_PHASE_PROC` | 初期プロセスの中 | 常に |
| `TST_PHASE_SELF` | 本来の起動列を通したあと | ESP に `\BTRON\SELFBOOT` があるときだけ |
